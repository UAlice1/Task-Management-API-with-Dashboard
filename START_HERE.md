## ⚡ Quick Start (Under 2 Minutes)

### Step 1️⃣: Start MongoDB (5 seconds)
Open **Command Prompt as Administrator** and run:
```bash
net start MongoDB
```

### Step 2️⃣: Start Backend (10 seconds)
Open a **new terminal** in this folder and run:
```bash
cd backend
npm start
```

Wait for: **"Server is running on port 5000"** ✅

### Step 3️⃣: Start Frontend (30 seconds)
Open **another new terminal** in this folder and run:
```bash
cd frontend
npm start
```

Browser will automatically open at: http://localhost:3000 🎉

---

## 🌟 OR Use This Super Simple Command

From the main project folder:
```bash
npm run dev
```

This starts **BOTH** backend and frontend at once!

## 🐛 Troubleshooting

### ❌ MongoDB won't start?
```bash
# Run Command Prompt AS ADMINISTRATOR
net start MongoDB
```

### ❌ Backend shows error?
- Make sure MongoDB is running
- Check if port 5000 is free
- Look at the error message in terminal

### ❌ Frontend won't connect?
- Make sure backend is running first
- Check if backend is at http://localhost:5000
- Refresh the browser page

### ❌ Port already in use?
- Close other applications using ports 3000 or 5000
- Or change PORT in `backend/.env`
